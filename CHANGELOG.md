# Журнал изменений

Версии по [Semantic Versioning](https://semver.org/lang/ru/): `MAJOR.MINOR.PATCH`.

- `MAJOR` — поколение реализации: 1 — bat-скрипты над esptool и STM32CubeProgrammer,
  2 — PowerShell (`legacy/`), 3 — Rust.
- `MINOR` — новая возможность (раздел, протокол, способ прошивки).
- `PATCH` — исправления и уточнения без новых возможностей.

Номер версии хранится в одном месте — `[workspace.package] version` в `Cargo.toml`.
Все крейты наследуют его, exe получает его при сборке через `CARGO_PKG_VERSION`
(заголовок меню, имя архива `dist\FPV-Flasher-<версия>.zip`). Каждый коммит, меняющий
поведение, поднимает версию и добавляет запись сюда; выпуск отмечается тегом `vX.Y.Z`.

## [3.1.0] — 2026-11-26

Первая версия на Rust и первая крупная возможность — протокол Walksnail.

### Добавлено
- Рабочее пространство Cargo: `app`, `core`, `fc`, `radio`, `walksnail`, `xtask`.
- Главное меню на Rust; пункт 1 запускает прежнее меню STM32 (`legacy\run.cmd`).
- Перечисление COM-портов с VID:PID без открытия, поиск DFU-загрузчиков STM32/AT32 через USB,
  `--ports`.
- Справочник устройств, ожидание появления и исчезновения устройства по VID:PID.
- Журнал сессии рядом с exe, очистка экрана и цвета только в настоящем терминале.
- Сборка архива из манифеста `vendor.sha256` с проверкой хэшей.
- Walksnail: описание протокола AR, кодек кадров с CRC32, разбор ответа устройства,
  заголовок `.img`, план обновления и `ArFileInfo`. Устройство пока не открывается.
