# Сторонние компоненты

Проект распространяется архивом вместе со сторонними инструментами. Ниже их состав, версии и
условия использования. Тексты лицензий лежат рядом с самими файлами в `vendor/` (в git не входят,
контрольные суммы — `vendor.sha256`).

## STM32CubeCLT (`vendor/STM32CubeCLT`)

- Назначение: `STM32_Programmer_CLI.exe` — чтение, запись и стирание flash полётных контроллеров STM32.
- Правообладатель: STMicroelectronics.
- Условия: лицензионное соглашение STMicroelectronics (SLA0044, «Ultimate Liberty»). Распространяется
  как отдельный исполняемый файл, не связывается с кодом проекта. Текст соглашения — на сайте ST и в
  комплекте поставки CubeCLT.
- В архив включается только `bin/` и минимально необходимый `Data_Base/`. Планируется замена
  собственным DFU-клиентом (этап 5), после чего зависимость уйдёт.

## CP210x Universal Windows Driver (`vendor/CP210x_Universal_Windows_Driver`)

- Назначение: драйвер USB-UART Silicon Labs CP210x (ESP-модули).
- Правообладатель: Silicon Laboratories.
- Условия: `SLAB_License_Agreement_VCP_Windows.txt` в каталоге драйвера.

## CH341SER (`vendor/CH341SER.EXE`)

- Назначение: драйвер USB-UART WCH CH340/CH341 (радиомодули и гимбали Caddx с VID 1A86).
- Правообладатель: Nanjing Qinheng Microelectronics (WCH).
- Условия: поставляется WCH как свободно распространяемый установщик драйвера.

## ImpulseRC Driver Fixer (`vendor/ImpulseRC_Driver_Fixer.exe`)

- Назначение: установка WinUSB-драйвера для STM32 DFU (VID 0483, PID DF11).
- Источник: ImpulseRC. Исходный код и лицензия публично не опубликованы.
- Статус: используется как есть, без модификации. Планируется замена собственной установкой WinUSB
  через Windows API (этап 5).

## ESPtool (`analyze/RadioModule/legacy-tools/ESPtool`)

- Назначение: прошивка ESP32 (в legacy-коде отключено, раздел переписывается).
- Версия: 5.4.0.
- Лицензия: GPL-2.0-or-later. Запускается как отдельный процесс, исходники доступны в репозитории
  Espressif. В состав нового Rust-бинарника не включается; планируется встроить MIT/Apache-библиотеку
  `espflash`.

## FC Passthrough flasher (`analyze/RadioModule/legacy-tools/FCPassthrough`)

- Назначение: прошивка ESP32 через полётный контроллер (legacy-код).
- Источник: Barvinok-5 team, v0.8. Исходный код и лицензия не опубликованы.
- Статус: в новый дистрибутив не войдёт, заменяется собственной реализацией MSP-моста.

## Caddx PC Tool v1.1.1 / 2.0.40 / 2.0.56 / 2.2.8 / 2.2.9 (`analyze/Walksnail`)

- Назначение: только для анализа протокола и восстановления логики прошивки Walksnail.
- Правообладатель: Caddx FPV. Пользовательское соглашение Caddx запрещает распространение и
  реверс-инжиниринг.
- В репозиторий и в дистрибутив не входят, лежат в `analyze/` (исключён из git). Код проекта не
  содержит декомпилированных фрагментов Caddx.

## ExpressLRS и ExpressLRS Configurator (`analyze/RadioModule`)

- Назначение: изучение сценариев сборки и прошивки радиомодулей.
- Лицензия: GPL-3.0 (см. `LICENSE` в каждом каталоге).
- В репозиторий и дистрибутив не входят. Используются как справочник; заимствование кода потребует
  соблюдения GPL-3.0, поэтому код пишется самостоятельно.

## ZLRS 3.36 (`analyze/RadioModule/Образец прошивок - ZLRS v3.36`)

- Назначение: образцы готовых прошивок для проверки собственного сценария записи.
- Права: принадлежат правообладателю ZLRS. В репозиторий не попадают.

## TProgrammerCLI (`analyze/FlightController`)

- Назначение: изучение логики автоматической прошивки полётных контроллеров.
- Автор: сторонний разработчик. В репозиторий и дистрибутив не входит.
